- 首次盤點日期：2026-10-30（民國115年10月30日）

> 「找不到資料」不等於「沒有資料」；「來源已同步」不等於「全部歷史文件均已收錄」。

## 三、合法擷取原則

1. 優先使用官方開放資料 API（全國法規資料庫、農業資料開放平臺）。
2. 對 HTML 網站：每次執行都即時讀取 `robots.txt`，不允許即不擷取；請求間隔至少 1.5 秒；每次失敗有限重試；以可識別之 User-Agent（含本專案網址）連線。
3. 不繞過登入、驗證碼、存取限制或反爬蟲機制。
4. 出版品全文（PDF）不鏡像，只保存書目及官方連結。

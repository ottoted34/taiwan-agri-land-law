# 官方資料來源盤點報告

- 首次盤點日期：2026-10-30（民國115年10月30日）
- 盤點方式：人工檢視官方網站＋GitHub Actions 主機實測（連線、robots.txt、實際頁面結構）
- 機器可讀版本：[`config/sources/registry.yaml`](../config/sources/registry.yaml)
- 之後由 `source-audit` 工作流程每月 1 日自動重新檢查連線及 robots 規則，結果見網站「資料來源」頁及 `data/metadata/source-audit-latest.json`

> 「找不到資料」不等於「沒有資料」；「來源已同步」不等於「全部歷史文件均已收錄」。

## 二之一、首次實際同步後之發現（2026-10-30）

- **RMIS 函釋列表分頁不穩定**：官方伺服器對部分頁碼（約第130–170頁）間歇性回應「目前無資料可顯示」，同一頁稍後重試又有資料。系統已實作每頁重試＋60 秒後第二輪補抓；仍無法取得時該次比對標示為「非完整」，不會將函釋誤判為下架。
- **「法規對應解釋函」頁含大量列表未收之函釋**：各法規之「解釋內容」頁另列 2,539 件未出現在「最新解釋函」列表之函釋（多為改制前農委會函釋，尤以農舍辦法最多），已全文收錄。此類頁面**不提供發文日期**，系統僅在字號文字含完整日期時採用；其餘標示「日期未載」，並依字號前三碼推估年度供排序（明確標示為推估）。
- **字號非唯一**：同一字號、同一日期可含多則不同解釋（如函釋彙編之編號 027、049），故函釋識別以「字號＋日期＋主旨」為準。
- **農業資料開放平臺**：每月自動搜尋得到 15 個試驗研究機構資料集；其中「高雄區農業改良場休耕地復耕生產技術服務團名冊」含人員姓名、電話、電子信箱，依個資原則排除；技術移轉公告、品種權清單非技術出版品，亦排除。

## 三、合法擷取原則

1. 優先使用官方開放資料 API（全國法規資料庫、農業資料開放平臺）。
2. 新來源評估：以 **diagnose** 工作流程之「來源評估」模式（輸入網址）自 GitHub Actions 讀取 robots.txt 與頁面，結果推送到 `diagnostics` 分支，不影響正式資料。
3. 對 HTML 網站：每次執行都即時讀取 `robots.txt`，不允許即不擷取；請求間隔至少 1.5 秒；每次失敗有限重試；以可識別之 User-Agent（含本專案網址）連線。
4. 不繞過登入、驗證碼、存取限制或反爬蟲機制。
5. 出版品全文（PDF）不鏡像，只保存書目及官方連結。

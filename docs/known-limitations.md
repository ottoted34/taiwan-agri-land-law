# 已知限制與下一階段工作

## 資料涵蓋

- **函釋**：目前自動收錄農業部農村發展及水土保持署「農地及農舍法規檢索系統」之通案函釋（最新解釋函列表約 1,500 件＋法規對應頁 2,539 件，共 4,040 件，民國89年起）。其中約 2,400 件官方頁面未載發文日期，無法比對修法先後。官方列表分頁間歇性空白，完整比對可能需多次執行才能補齊。個案函復、未公開於該系統之函釋、農糧署及其他機關自行發布之函釋**未收錄**。
- **農糧署**：網站 robots.txt 不允許自動擷取，相關函釋與農作產銷設施文件需人工補充或申請開放資料。
- **試驗研究機構**：官網自 GitHub 海外主機無法連線；技術資料目前僅收錄農業資料開放平臺上架之出版品書目（每月自動搜尋擴充）。農業試驗所尚未在平臺查得出版品目錄資料集。
- **法規歷史版本**：全國法規資料庫開放資料只有現行版本。歷史全文來自 RMIS 歷史沿革（僅部分版本有全文）。本站開始運作後每次修正都會保存快照。
- **附表**：僅連結官方 PDF，未將附表內容結構化；設施種類與面積限制請直接查閱官方附表。
- **地方自治法規**：資料結構已預留，尚未完成任何縣市查核。

## 功能

- **AI 問答**：未實作。原因：靜態網站無法安全保管 API 金鑰，且目前無符合免費、可防濫用條件之方案。案件審查輔助為檢索與規則式工具。
- **關聯精確度**：系統比對之法條關聯依函釋文字之「法規名稱＋條號」，可能因簡稱、舊條號（全文修正前）而誤連或漏連。修法影響標示亦以沿革文字推算條號，請人工確認。
- **效力判斷**：系統只提示疑義，不判斷效力。
- **搜尋**：以子字串比對，不具語意搜尋；同義詞表需人工維護（`config/synonyms/search_synonyms.yaml`）。
- **施行日期**：全國法規資料庫多數法規未提供施行日期欄位，以修正發布日期呈現並提示以官方公告為準。

- **Git 歷史**：初次同步時曾短暫收錄一個含公務人員聯絡資料之開放資料集（已排除並刪除），但仍存在於 Repository 早期提交歷史中；如需徹底清除須改寫歷史（force push），需 Repository 擁有者決定。

## 下一階段工作清單

1. 臺中市農地相關自治法規、審查要點查核與收錄。

4. 人工確認常用函釋之效力，累積 `manual.yaml`。
5. 評估國內 self-hosted runner 以收錄試驗研究機構官網資料。
6. 評估 RAG 式 AI 問答（需後端與費用評估，須經同意）。
